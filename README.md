Project Description

Button Museum is an intentionally useless interactive website filled with ridiculous buttons that perform absolutely unnecessary actions. Every button has its own personality, animations, reactions, and increasingly chaotic behavior.

The more you click, the more useless the website becomes.

The Problem (that doesn't exist)

Humanity has suffered for too long without a centralized place to press buttons that accomplish absolutely nothing.

People waste their time on useful websites every day. There was clearly a need for a platform where users can proudly waste their time while achieving nothing.

The problem: There aren't enough completely unnecessary buttons on the internet.

The Solution (that nobody asked for)

We built Button Museum, a digital museum dedicated to useless buttons.

Visitors can:

Press buttons that do nothing.
Press buttons that pretend to do something.
Make fake money.
Increase fake intelligence.
Download imaginary RAM.
Try to solve world problems.
Accidentally make things worse.
Summon developers who never appear.
Destroy buttons that immediately come back.
Waste increasingly large amounts of time.

Every button has a unique reaction, animation, or personality.

Implementation
For Software:

The website is built as a collection of reusable interactive button components.

Each button has its own:

Click counter
State
Personality
Response messages
Animation
Chaos level
Unlock conditions
Repeated-click behavior

The project also maintains persistent user progress using browser storage/database functionality.

Some buttons intentionally behave differently after repeated clicks, creating increasingly ridiculous outcomes.

Examples include:

DO NOT CLICK
        ↓
User clicks
        ↓
Button becomes angry
        ↓
User keeps clicking
        ↓
Button moves
        ↓
Button becomes even more annoyed

Another example:

MAKE ME RICH
      ↓
$0
      ↓
$0.01
      ↓
$0
      ↓
Congratulations!
You are still poor.
Installation

Clone the repository:

git clone https://github.com/plasticplayboyy/button-museum.git

Enter the project directory:

cd button-museum

Install dependencies:

npm install
Run

Start the development server:

npm run dev

Then open:

http://localhost:3000
